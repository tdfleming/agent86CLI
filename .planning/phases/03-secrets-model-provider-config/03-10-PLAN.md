<objective>
Close UAT gaps 1 and 4 — the two TUI-layer defects found during human verification of Phase 3.

Gap 1 (blocker, SEC-01/D-10): the raw `sk-ant-...` key typed into `KeyEntryModal` is echoed into
the transcript and dispatched to the model as a real turn, because the modal never calls
`event.stop()` and `Agent86App.on_input_submitted` accepts `Input.Submitted` from any `Input`.

Gap 4 (blocker, MODEL-01): a key already stored in the OS keyring is ignored on the second and
subsequent connection tests — `_on_test_done` clears `_pending_key` to `None`, and `None` is not
the `UNRESOLVED` sentinel, so `provider_for_ref` skips keyring resolution entirely and raises
"No Anthropic API key found".

Both gaps modify `src/agent86/tui/app.py`, so they are deliberately closed in one plan to avoid a
parallel write conflict.

Purpose: without gap 1, using the feature leaks the user's secret into the transcript and to a
third-party model. Without gap 4, the add-a-provider flow only ever works once per session.
Output: two fixed modals, a guarded App submission handler, an `UNRESOLVED` pass-through, and a
new regression-test module that fails on the pre-fix code.
</objective>
