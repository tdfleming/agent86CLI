<objective>
Close UAT gap 3 (blocker): an incompatible Anthropic SDK produced an opaque
`Client.__init__() got an unexpected keyword argument 'proxies'` TypeError from deep inside
httpx, and — because `model.default` had become `anthropic:claude-opus-5` and the key resolved
from the keyring — that construction happened at STARTUP inside `_Repl.__init__`, so `agent86`
could not boot at all and dumped a full traceback (which is also what leaked the key, UAT gap 2).

Root cause: installed `anthropic` was 0.25.9 against `httpx` 0.28.1. `anthropic` < 0.28 passes
`proxies=` to `httpx.Client(...)`, which httpx removed in 0.28. `pyproject.toml:26` already
declares the correct floor (`anthropic>=0.40`); the environment simply had a stale pin held by an
unrelated `anthropic-tools 1.0.7` sharing global site-packages.

**THE ENVIRONMENT IS ALREADY FIXED** — the user upgraded to `anthropic` 0.120.2 during the UAT
session and `anthropic.Anthropic()` now constructs against httpx 0.28.1. **Do NOT plan, run, or
deliver a `pip install` as the fix.** What is outstanding is code-level hardening so this class of
failure is legible next time it happens on someone else's machine.

Purpose: an incompatible or stale SDK must produce a message that names the fix, exactly the way
the missing-package path already does — and must never take the app down with a traceback.
Output: a version guard in `AnthropicProvider.__init__` and an integration test proving the
startup path degrades to "Cannot start:".
</objective>

    ```python
    #: Must match the floor declared in pyproject.toml's `anthropic` extra. Versions below 0.28
    #: pass `proxies=` to httpx.Client, which httpx removed in 0.28 — the failure surfaces as an
    #: opaque TypeError from inside httpx rather than anything actionable (UAT gap 3).
    _MIN_ANTHROPIC_VERSION: tuple[int, ...] = (0, 40)


    def _version_tuple(raw: str) -> tuple[int, ...]:
        """Leading numeric components of a version string; stops at the first non-numeric part."""
        parts: list[int] = []
        for chunk in raw.split("."):
            digits = ""
            for ch in chunk:
                if not ch.isdigit():
                    break
                digits += ch
            if not digits:
                break
            parts.append(int(digits))
        return tuple(parts)
    ```
